# 本地解析器（local engine）能力边界

`paper2html_convert` 默认走**本地解析**：插件内置的 `python/parsers/local_parser.py` 用 PyMuPDF
读取 PDF，抽标题、作者、正文、标题层级与插图，再交给上游渲染层排版。**不需要任何 key、不联网。**

## 它擅长什么

- 原生数字排版 PDF（LaTeX / Word 导出 / arXiv 大部分论文）；
- 单栏论文（Transformer、Mamba 这类）：标题/章节层级还原准确；
- 常规双栏论文（IEEE / CVPR 风格）：按左右栏顺序启发式拼装，多数情况可读；
- 论文插图：按页面位置抽到 `images/` 并 base64 内嵌进 HTML（自动过滤 logo、小图标、超大图）；
- 跨行断词、页码、页眉页脚、arXiv 水印、竖排免责声明等噪声会被过滤。

## 它做不到（重要）

| 内容 | 本地解析结果 | 建议 |
|---|---|---|
| 数学公式 | 以文本/符号碎片出现；KaTeX 可能渲染不完整 | 配置 Doc2X/PDF2X key 用云端解析 |
| 表格 | 退化成段落文本，丢失行列结构 | 同上 |
| 扫描件 | **无法解析**（没有文本层），报「可能是扫描件」 | 先 OCR，或用 Doc2X/PDF2X |
| 复杂版式 | 三栏、侧边注、图文混排可能串行 | 云端解析 |
| 参考文献 | 保留为纯文本段落，超链接丢失 | 无（不影响阅读） |
| 双栏精确顺序 | 启发式：先左栏后右栏、跨栏块按位置插入，偶有串行 | 云端解析 |

## 体积与性能

- 一篇 15 页的单栏论文约 0.3–1.5 MB HTML；图多的 40 页 survey 可能到 5–15 MB。
- 图片上限：单篇最多 80 张、单张 ≤4MB、总原始图 ≤20MB，超出会跳过并在 `warnings` 里提示。
- 转换耗时：本地解析 5–30 秒（不含首次安装依赖）。

## 想升级解析质量时

1. 配置 `DOC2X_APIKEY`（推荐）或 `PDF2X_APIKEY`，见 `references/api-keys.md`；
2. 工具本身不用改参数——引擎为 auto 时会自动优先云端、失败回退本地（`engine` 字段会返回 `doc2x`/`pdf2x`/`local`）；
3. 云端解析结果里公式会以 `$...$` 保留，页面 KaTeX 原生渲染。

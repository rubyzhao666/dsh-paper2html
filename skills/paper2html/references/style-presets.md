# 三套主题（style presets）

`paper2html_convert` 的 `style` 参数（可选 `dark_lab` / `clean_paper` / `neon_tech`，默认 `dark_lab`）。
同一篇论文重新转换时会生成带主题后缀的新文件，不会覆盖其他主题的版本。

## dark_lab（默认）

- 深色背景 + 绿色强调色，适合夜间阅读、长时间盯屏幕。
- 代码块/公式在深色下对比度最好；卡片阴影偏冷。
- 适用：自己读、录屏讲解。

## clean_paper

- 白底 + 学术蓝强调，接近纸面阅读；打印友好。
- 截图贴进笔记、飞书/Notion 文档时最不违和。
- 适用：正式分享、课堂、给不熟悉深色主题的同事。

## neon_tech

- 深紫背景 + 霓虹强调，视觉冲击强；偏「科技产品发布会」气质。
- 适用：演示、社媒展示、想让页面本身成为亮点的场景。

## 共同点 / 切换方式

- 页内左下角有主题下拉框，打开一次即可在前端实时切换三套主题（无需重新转换）。
- 页面内三种阅读模式：速读（摘要为主）、标准（默认）、精读（隐藏摘要卡、突出全文）。
- 目录、锚点复制、⌘K 搜索、阅读进度条等交互三套主题一致。
- KaTeX（公式）与 Mermaid（架构图）由 CDN 加载：**联网时**公式/图表渲染最完整；离线打开时正文仍可读。

## 怎么选

| 用户意图 | 推荐 |
|---|---|
| 没说 / 自己看 | `dark_lab` |
| 打印、贴文档、正式分享 | `clean_paper` |
| 演示、社媒、要「炫」 | `neon_tech` |
